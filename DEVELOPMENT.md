# UFC Combat — игровой прототип

Запуск: `cd arena`, затем `npm start`. Открыть http://127.0.0.1:4173.

Проверки: `npm test`.

Без сборки и зависимостей: HTML, CSS, JavaScript. Готовая статика — `dist/`.

Реализованы 89 виртуальных бойцов, поиск, карточки, создание своего бойца с изображениями, демобаланс, временная поддержка, автоматические бои, травмы, восстановление, усталость, сетка на 8 бойцов, ротация турниров, история и награды. Флаги регионов не комплектуются: общий флаг России или загрузка своего изображения.

Время ускорено ×6. Симуляция работает только в открытой вкладке; фоновые вкладки могут замедляться браузером. Состояние сохраняется в localStorage. Это одиночный демонстрационный мир, без общего сервера, авторизации и реальных платежей. Баланс — предварительная модель, а не подтверждённые вероятности победы.

Для круглосуточной общей лиги следующий этап: серверная симуляция и БД, аккаунты, серверная проверка поддержки, платёжные вебхуки с защитой от повторного начисления. Клиентский демобаланс нельзя использовать для реальных денег.

Внешний ресурс оформления: Google Fonts. Системные шрифты используются как запасные. Аватары по умолчанию нарисованы SVG в коде.
