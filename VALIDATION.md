# Проверки версии 2.3.2

26 октября 2026 года, Node.js 24.20.0.

- `npm test`: все 61 проверка игровых модулей, единого мира, HTTP, авторизации, хранения, платежей и интерфейса прошли. Проверено, что test_no_receipt работает только в test и запрещён в live.
- Виртуальные зрители: отдельные поля API от измеренного онлайна, 2–5 распределённых по времени поддержек, сохранение плана и позиции после перезагрузки, одно временное очко за событие. Балансы, денежная статистика, казна и пользовательский счётчик поддержек не меняются; после завершения боя события не исполняются.
- ЮKassa проверена на имитации API: сохранение заказа до POST, повторные запросы и webhook без повторного кредита, проверка суммы/валюты/метаданных/магазина/test-live, сетевой обрыв и граница идемпотентности, SQLite-перезапуск, возврат один раз, платные списания после очистки игровых квитанций.
- Проверены раздельные кошельки: бесплатные очки не становятся платными, пари не меняют платный баланс, тестовые платежи не создают боевых средств. UI открывает форму оплаты, передаёт сумму/email и повторяет тот же requestId перед переходом на страницу ЮKassa.
- С предоставленным тестовым ключом выполнены запрос списка платежей (HTTP 200) и создание одного тестового платежа на 100 ₽ (pending, test=true, ссылка ЮMoney получена). Заказ хранится в отдельной локальной тестовой базе. Банковская оплата, реальные чеки и доставка живого webhook не проверялись. На публичном сайте до обновления обнаружена версия 2.2.0; установка выполняется отдельно другим чатом.
- Очистка: ограничения завершённых ставок и квитанций, сохранение открытых ставок и денег, однократное сворачивание итогов, награды и актуальная хроника.
- Проверены московская полночь и один отчёт вместо растущего журнала, удаление только истёкших auth-записей, восстановление пустого старого профиля по сохранённому GUID.
- Проверено реальное уменьшение SQLite после удаления тестовых 12 МиБ: баланс и GUID сохраняются, integrity_check возвращает ok.
- GUID: отдельный код для новых cookie, сохранение кода после обновления страницы, вход со второго устройства с восстановлением баланса/ставок/владения, отсутствие чужих кодов в публичном мире.
- Блокировка: ровно 24 часа, сохранение после перезапуска, запрет обхода очисткой cookie и поддельным X-Forwarded-For, автоматическое истечение, продолжение просмотра и действующих сессий.
- Проверены миграция старого гостя без потери кошелька, UI меню GUID и поля входа, отсечение запоздалых ответов после смены профиля и отзыв прежней cookie.
- Проверяются два независимых посетителя: один бой и поддержка, разные балансы и ставки, общие лайки и созданные бойцы.
- Проверяются идемпотентность поддержки, закрытие приёма, валидация пакетов, расчёт ставок на сервере, выплаты по общему результату.
- Проверяются сохранение SQLite, полный откат неуспешного действия, повтор после перезапуска и восстановление согласованной резервной копии.
- Интерфейс проверяется через DOM-заглушки с настоящим обработчиком команд: профиль, поддержка, лайки, ставка, создание бойца и восстановление связи. Браузер больше не продвигает время симуляции.
- Проверяются Origin, сокрытие чужих кошельков, запрет выдачи файла базы по HTTP и заголовки кэширования.
- Локальный процесс на порту 4173 проверен HTTP-запросами: 429 бойцов, sharedWorld=true, серверное время продвигается, /api/health возвращает ok=true и catchingUp=false. Команда npm run backup создала копию работающей базы.
- В локальном процессе 2.3.2 проверены выдача GUID и успешный вход второй сессии; чужие коды не попадают в состояние мира. Сами секретные коды в отчёты не выводились.

Графического браузера в текущей среде нет: визуальная проверка настоящих вкладок не проведена. Docker-образ не собирался. Нагрузочное тестирование и работа нескольких серверов не заявляются; приложение рассчитано на один процесс с постоянным диском. Установка на внешнем сайте выполняется отдельно по DEPLOYMENT.md.
