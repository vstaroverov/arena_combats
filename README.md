# ЯРОСТЬ

Браузерная игра — симулятор бойцовской лиги с **единым серверным миром для всех посетителей**. Наблюдайте за боями, поддерживайте бойцов, развивайте своего участника и следите за турнирами от городских отборов до суперфинала.

Версия **2.3.5**. Бои идут на сервере даже без зрителей. Все видят одинаковых бойцов, турнирные сетки, поддержку, лайки и результаты; баланс и ставки у каждого свои. Доступ к личному профилю с другого устройства восстанавливается по GUID-коду.

## Возможности

- 429 стартовых бойцов из регионов и крупных городов России.
- Профили с аватаром, региональным флагом, характеристиками, рейтингом, победами, поражениями, травмами и наградами.
- Автоматические бои с событиями, уроном, усталостью и восстановлением. На результат влияют характеристики, поддержка и случайность.
- Виртуальные зрители с пометкой «симуляция», отдельно от реального онлайна. Их число плавно меняется по московскому времени: утром и вечером больше, ночью и днём меньше, с небольшими случайными колебаниями. Они делают 2–5 случайных поддержек за полный раунд; временное усиление учитывается отдельно от пользовательских оплат.
- Городские, региональные и межрегиональные турниры, виртуальный Кубок мира и суперфиналы сезонов.
- Поддержка в текущем бою и подготовка к будущим встречам, лайки и создание собственного бойца.
- Кнопки лайка под обоими бойцами текущего боя. Виртуальные зрители периодически добавляют свои лайки, которые отмечены как симуляция и считаются отдельно от пользовательских.
- Виртуальные ставки на победителя турнира с коэффициентами, призовые и монеты арены для развития навыков.
- Счётчики посетителей и зрителей боя при запуске Node-сервера.
- Адаптивный интерфейс, фавиконы и SEO-метаданные.

## Быстрый запуск

Нужен **Node.js 24+**. Сторонних npm-зависимостей и отдельного этапа сборки нет.

```sh
git clone https://github.com/vstaroverov/arena_combats.git
cd arena_combats
npm start
```

Откройте **http://127.0.0.1:4173**. Проверка игровой логики:

```sh
npm test
```

## Развёртывание

Интерфейс находится в `dist/`. Node-сервер ведёт симуляцию, принимает действия игроков, раздаёт сайт и считает зрителей. Доступны настройки `HOST`, `PORT`, `PUBLIC_ORIGIN`, `WORLD_DB` и Dockerfile.

Команды для VPS, Docker и HTTPS-прокси — в [DEPLOYMENT.md](DEPLOYMENT.md). **Статического хостинга недостаточно:** нужен постоянно работающий Node-процесс и постоянный диск для SQLite. Запускайте один экземпляр сервера для одного мира.

## Хранение и игровая экономика

Общий мир и личные кошельки сохраняются на сервере в `data/world.sqlite`. Поддержка, ставки и выплаты проверяются сервером и записываются атомарно; повтор доставки одного действия не вызывает повторного списания. После перезапуска сервер продолжает сохранённый мир и догоняет прошедшее время.

Новый посетитель автоматически получает профиль, **секретный GUID-код доступа** и сессию в HttpOnly-cookie. Код показан в меню **«Мой GUID / Войти»**: сохрани его и используй на другом устройстве или после очистки cookie. Вкладки одного браузера используют один кошелёк. При входе по коду восстанавливаются личный баланс, ставки, лайки и свои бойцы; профили не объединяются.

Один неверный GUID блокирует **вход по коду на 24 часа** для текущего браузера и IP. Очистка cookie и перезапуск сервера блокировку не снимают. Просмотр арены и уже действующие сессии остаются доступны. В общей сети блок затрагивает попытки входа по GUID с того же IP. Без cookie и сохранённого кода восстановление доступа не предусмотрено.

Старые локальные сохранения версии 1 остаются в браузере и автоматически не импортируются: у разных посетителей они описывают разные миры.

Есть два раздельных кошелька. **Бесплатные игровые очки** используются для пари и виртуальных выигрышей; они не продаются и не конвертируются в деньги. **Платный баланс** пополняется через ЮKassa и расходуется только на поддержку и создание бойцов. Вывода денег из игры нет. Старые игровые средства не превращаются в купленные единицы.

Интеграция ЮKassa подготовлена, но по умолчанию выключена: владелец ещё предоставит магазин и домен. Настройки магазина, секретного ключа на сервере, webhook и чеков — в [PAYMENTS.md](PAYMENTS.md). В тестовом режиме настоящие деньги не списываются и боевой платный баланс не пополняется. Реальные платежи пока не проводились.

Резервная копия работающей базы: `npm run backup`. Папки `data/` и `backups/` не включаются в Git. При обновлениях сохраняйте файл базы и тот же домен; инструкция по обновлению и откату находится в [DEPLOYMENT.md](DEPLOYMENT.md).

Временные данные очищаются при запуске и после полуночи по Москве. Завершённые ставки хранятся до 30 дней и не более 100 на профиль, квитанции действий — до 7 дней и не более 200, награды — 50 последних плюс общий счётчик. Открытые ставки, балансы, GUID и прогресс сохраняются. Истёкшие сессии и блокировки удаляются, свободное место SQLite переиспользуется и при необходимости уплотняется. Полная политика — [RETENTION.md](RETENTION.md).

## Структура

| Путь | Содержимое |
| --- | --- |
| `dist/` | Интерфейс, игровые модули, флаги и иконки |
| `server.mjs`, `presence.mjs` | HTTP-сервер и счётчики зрителей |
| `world.mjs`, `game.mjs`, `store.mjs` | Единая симуляция, действия игроков и SQLite |
| `identity.mjs` | GUID-коды, сессии и блокировки входа |
| `payments.mjs`, `PAYMENTS.md` | ЮKassa, раздельный платный кошелёк и платёжный учёт |
| `retention.mjs`, `maintenance.mjs` | Ограничения истории и ежедневная очистка |
| `dist/client.js` | Получение состояния и отправка действий на сервер |
| `test/` | Автоматические проверки |
| `scripts/` | Подготовка ресурсов и справочников |
| `SEO_CORE.md` | Семантическое ядро и настройки публичного домена |
| `FLAG_SOURCES.md`, `CITY_SOURCES.md` | Источники флагов и данных о городах |
| `GAME_IDEA.md` | Концепция игры |
