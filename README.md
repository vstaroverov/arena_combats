# ЯРОСТЬ

Браузерная игра — симулятор бойцовской лиги. Наблюдайте за боями, поддерживайте бойцов, развивайте своего участника и следите за турнирами от городских отборов до суперфинала.

## Возможности

- 429 стартовых бойцов из регионов и крупных городов России.
- Профили с аватаром, региональным флагом, характеристиками, рейтингом, победами, поражениями, травмами и наградами.
- Автоматические бои с событиями, уроном, усталостью и восстановлением. На результат влияют характеристики, поддержка и случайность.
- Городские, региональные и межрегиональные турниры, виртуальный Кубок мира и суперфиналы сезонов.
- Поддержка в текущем бою и подготовка к будущим встречам, лайки и создание собственного бойца.
- Виртуальные ставки на победителя турнира с коэффициентами, призовые и монеты арены для развития навыков.
- Счётчики посетителей и зрителей боя при запуске Node-сервера.
- Адаптивный интерфейс, фавиконы и SEO-метаданные.

## Быстрый запуск

Нужен **Node.js 24+**. Сторонних npm-зависимостей и отдельного этапа сборки нет.

```sh
git clone https://github.com/vstaroverov/arena_combats.git
cd arena_combats
npm start
```

Откройте **http://127.0.0.1:4173**. Проверка игровой логики:

```sh
npm test
```

## Развёртывание

Готовые файлы сайта находятся в `dist/`. Node-сервер раздаёт сайт и обслуживает `/api/presence` для счётчиков зрителей. Доступны настройки `HOST`, `PORT`, `PUBLIC_ORIGIN` и Dockerfile.

Подробные команды для VPS, Docker, HTTPS-прокси и статического хостинга — в [DEPLOYMENT.md](DEPLOYMENT.md). При публикации на статическом хостинге без API счётчики зрителей показывают «—».

## Хранение и игровая экономика

Бойцы, турниры, баланс, ставки и прогресс сохраняются в `localStorage` браузера. У каждого браузера свой игровой мир; симуляция работает, пока открыта вкладка. Общая серверная лига и аккаунты пока не реализованы.

Все суммы и ставки — **виртуальные игровые средства**. Пополнение бесплатное; реальных платежей и вывода денег нет. Node-сервер хранит в памяти только присутствие зрителей. Подробности реализации и проверок — в [DEVELOPMENT.md](DEVELOPMENT.md) и [VALIDATION.md](VALIDATION.md).
