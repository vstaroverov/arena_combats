Нужно развернуть ЯРОСТЬ версии 2.3.5 — браузерную игру с единым серверным миром для всех и входом по секретному GUID.
Прочитай README.md и DEPLOYMENT.md. Требуется постоянно работающий Node.js 24+, один процесс, постоянный диск SQLite и HTTPS reverse proxy на весь сайт, включая /api/.
WORLD_DB должен указывать на постоянный файл базы вне заменяемого каталога выпуска. При обновлении не создавай новую базу и не удаляй прежнюю. Для Docker сохрани тот же volume /app/data.
Не публикуй только dist/: без Node-сервера общий мир не работает. Клиентской офлайн-симуляции нет.
Настрой PUBLIC_ORIGIN под настоящий HTTPS-домен, HOST и PORT под хостинг. Сервер сам продолжает бои без зрителей и восстанавливает мир после перезапуска.
Старые локальные сохранения версии 1 не объединяются в общий мир; их localStorage не удаляется. Посетители получают GUID-код доступа и HttpOnly-cookie. GUID восстанавливает профиль с другого устройства. Ошибка кода блокирует вход по GUID на 24 часа для браузера и IP, блок хранится в SQLite. Балансы и бесплатные пари личные, бойцы и результаты общие.
Для установки тестовой ЮKassa на arena.v-star-group.ru сначала прочитай TEST_DEPLOYMENT.md и PAYMENTS.md. Тестовый магазин 1509255, режим test_no_receipt; секрет отдельно в окружении сервера, в архиве его нет. payments.mjs обязателен в runtime. Платный баланс только для поддержки и создания бойцов; пари используют бесплатные очки. Тестовые средства не пополняют боевой баланс. Не включай реальные платежи. Сохрани текущую базу мира, GUID и переменные сервера при обновлении с 2.2.0, не подставляй новую тестовую базу вместо действующей. После реальных оплат нельзя откатывать базу к старой копии без сверки платежей.
При обновлении с 2.0 кошельки и cookie сохраняются, GUID выдаются автоматически без сброса мира. identity.mjs обязателен в runtime. Не публикуй базу или GUID-коды.
В версии 2.2 добавлена автоматическая очистка истории и истёкших сессий: retention.mjs и maintenance.mjs обязательны в runtime. Прочитай RETENTION.md. Очистка запускается на старте и после московской полуночи; балансы, GUID, бойцы и открытые ставки сохраняются. Отдельно настрой ротацию внешних логов и резервных копий на хостинге.
За одним доверенным reverse proxy настрой TRUST_PROXY=1 и корректный X-Forwarded-For реального клиента, закрой Node-порт от прямого доступа. Иначе оставить TRUST_PROXY=0. Подробнее — DEPLOYMENT.md.
Запусти npm test, проверь /api/health, два разных браузера/сессии, общую поддержку и перезапуск с той же базой. Перед обновлением сделай согласованный backup. Схема версии 3; схема 2 обновляется автоматически с сохранением бесплатных очков и без выдачи платных средств. Не сбрасывай данные при ошибке открытия базы. Старый код схемы 2 не должен открывать новую платёжную базу.
Добавь canonical, og:url и sitemap.xml под реальный домен, проверь SEO и фавиконы. Коммерческое использование требует отдельного письменного разрешения автора по LICENSE.
